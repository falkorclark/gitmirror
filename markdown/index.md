
# Introduction 
The GitMirror project is a cross-platform command line utility for maintaining Git mirrors. The 
script can manage any number of mirrors across multiple servers. The project allows for single
repository mirroring or multi-repository mirroring along with the ability to cherry-pick specific
branches to mirror. It also allows for two-way mirroring under specific circumstances.
